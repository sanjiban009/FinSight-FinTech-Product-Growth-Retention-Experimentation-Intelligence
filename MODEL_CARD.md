# Model Card — Synthetic Next-Month Inactivity Prediction

**Model family:** Scikit-learn logistic regression in a pipeline with numeric standardization and categorical one-hot encoding.

**Intended use:** Demonstrate the complete workflow of constructing historical observation windows, separating training and time-based holdout data, evaluating class probabilities, and surfacing user-level churn risk in a BI interface.

**Not intended for:** Any real customer treatment, financial decision, credit assessment, pricing, sensitive demographic inference, surveillance, or claims about CoinDCX's user base.

**Prediction target:** For a synthetic user at the end of a given calendar month, probability of **no recorded app activity in the following complete calendar month**.

**Features available at scoring time:** Current/latest month sessions; active months in the most recent three months; total sessions in three months; number and notional of trades in three months; account tenure; number of months since last observed activity; behavior segment, acquisition channel and device.

**Training strategy:** Generate monthly snapshots for users with accounts opened by the snapshot month. Train on synthetic snapshots from February 2025 to August 2026 and validate on a future-month slice: **September 2026 feature snapshot predicting October 2026 activity**. This chronological split avoids random mixing of overlapping month snapshots across the validation boundary, although the same synthetic users can appear at different dates.

**Performance on synthetic temporal holdout:**

| Metric | Result |
|---|---:|
| Training month snapshots | 40,812 |
| Temporal holdout snapshots | 3,623 |
| Positive class prevalence | 56.69% |
| ROC-AUC | 0.7702 |
| PR-AUC | 0.7937 |
| Brier score | 0.1973 |

**Scoring:** User scores shown in the dashboard use the **October 2026** feature snapshot; November 2026 is not used as a model feature. Nov 2026 signup records have blank scores because they did not exist at October month-end.

**Risk classification (presentation only):** Low below 40%; medium 40%–69.9%; high 70% or greater.

**Bias and model validity:** The simulation defines synthetic behavior, segments and growth channels. Its coefficients and validation metrics cannot be transferred to any actual user population, and the dataset lacks important sources of business drift. Demographic fairness cannot be assessed on these invented, nondemographic fields. An actual model would require security and privacy review, calibration, feature data-quality checks, prospectively monitored performance, fairness testing and human review of intervention policies.

**Version/reproducibility:** Generated by `tools/generate_dataset.py`, seed 261113. Scoring is deterministic given dependencies and input generation. `data/csv/ModelValidation.csv` reports the summarized run results.
